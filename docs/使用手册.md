# HarSnap 使用手册

> 承接 README。README 写总览，本文写权限、边界、FAQ 与故障排查的完整细节。

## 一、权限逐项说明

安装时 Chrome 会提示以下权限，每个都有明确用途、无一多余：

| 权限 | 用途 | 为什么需要 |
|---|---|---|
| `debugger` | 通过 CDP 捕获完整网络请求（含响应体） | 不开 DevTools 也能拿到请求/响应/cookie/token 的唯一途径 |
| `downloads` | 下载 HAR / Cookie / Token / 清单文件 | 导出录制结果 |
| `activeTab` | 定位你当前正在看的标签页 | 「开始录制」时挂到正确页面 |
| `tabs` | 读取当前标签页信息 | 配合 activeTab 精确定位 |
| `storage` | 缓存录制结果 | popup 关闭再打开，结果不丢 |

> HarSnap **不申请** `cookies` 权限（那是浏览器扩展读 Cookie 的专用 API，权限敏感），而是从网络请求的 Cookie 头里提取——拿到的信息一样，但权限更轻、更不容易被拒。

## 二、已知边界

### 2.1 「正在调试」黄色提示条

用 `chrome.debugger` 录制时，浏览器顶部必然出现「此标签页正在被调试」的黄色横幅。**这是 Chrome 的安全机制，无法隐藏**。

- 录制期间**不要关**它，一关录制就中断（`onDetach` 自动收尾）。
- 它只在你录制的那个标签页出现，不影响其他标签页。

### 2.2 单标签页单调试器

一个标签页同时只能有一个调试器。所以：

- 录制时**不要同时打开该标签页的 DevTools**，否则 attach 失败或互相干扰。
- 要么用 HarSnap 录制，要么用 DevTools 手动导出，二选一。

### 2.3 超大响应体

CDP 对超大响应体（几百 MB）会拒绝返回 body，此时该请求**只有 headers / status，没有 body**。

- 签到场景的响应都很小（几 KB 的 JSON），基本碰不到。
- 若录制大文件下载类页面，那些请求会缺 body，属正常。

### 2.4 浏览器支持

- ✅ Chrome / Edge / Brave 等 **Chromium 系**浏览器。
- ❌ Firefox：WebExtensions 在 `debugger`/CDP 这块差异较大，需另做，暂不支持。

## 三、FAQ

**Q：Token 和 Cookie 有什么区别，为什么都要提取？**
Cookie 是浏览器自动带的登录态；Token 是放在 `Authorization: Bearer xxx` 请求头里的凭证。很多现代站点（尤其前后端分离的）登录态根本不在 Cookie 里，只在 Token 里——只抓 Cookie 会漏掉这一类。所以两者并列提取。

**Q：导出的 HAR 里有我的密码吗？**
有登录态（cookie / token），但密码本身通常只在登录那一刻的 POST body 里。**HAR 是明文凭证，别公开分享**，和对待密码一样对待它。

**Q：能只导出一个请求吗？**
能。结果区「请求范围」选「仅勾选」，在请求列表勾中你要的那个（比如签到 POST），下载的 HAR 就只含它。

**Q：为什么是多选下载，不是打包成 zip？**
为保持零依赖、无构建步骤，不做 zip 打包。勾几项就依次下载几个文件（各自弹保存框）。

## 四、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 点「开始录制」没反应 | 当前标签页是 `chrome://` 等受保护页面 | 切到普通网页再录 |
| 黄色提示条不见了，录制也停了 | 你（或误触）关了提示条 | 重新开始录制 |
| 请求数为 0 | 开始录制后没在页面操作 | 录制中要实际点一次签到/刷新 |
| 某请求没响应体 | 响应体过大，CDP 拒返 | 属正常，headers/status 仍在 |
| 下载没反应 | 浏览器禁止了自动下载 | 检查下载设置，或点「下载所选」手动触发 |

## 五、与 DailyCheckin 配合（可选）

HarSnap 是独立插件，不绑定任何后端。但它导出的产物正好能喂给 NAS 签到工具：

1. 用 HarSnap 录一次签到，导出 **HAR**（含 cookie/token）和 **Cookie** 列表。
2. 在 DailyCheckin 面板「+ 添加签到任务」上传 HAR，Cookie 列表填进「Cookie 变量」。
3. 完成托管，此后由 DailyCheckin 定时重放，不再需要 HarSnap。
